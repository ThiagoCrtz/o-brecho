# Segurança

Esta versão não foi implantada em produção. A interface ainda usa acesso e dados demonstrativos;
o backend possui autenticação e autorização próprias.

Não publique senhas, tokens, dados pessoais reais ou cópias de banco em issues, commits ou exemplos.
Use somente dados fictícios ao reproduzir problemas.

Para relatar uma vulnerabilidade, entre em contato diretamente com o mantenedor pelo perfil
do GitHub antes de publicar detalhes que permitam exploração. Se a opção de relatório privado
estiver disponível na aba Security, use esse canal.

Consulte [proteções e limites do backend](backend/README.md#autenticação-e-proteção)
e execute os testes antes de alterar autenticação, permissões, estoque ou vendas.

A publicação do código não equivale a uma certificação de segurança nem à implantação do sistema.
